How to use Notibrate

Setting up takes a couple of minutes. Here's what to do.

  1. Give Notibrate notification access

    When you first open Notibrate, it asks for Android's notification access. This is required so Notibrate can see when an app is posting a notification, allowing it to play the right vibration pattern.

    Android shows a standard warning for any app that asks for this. Notibrate never reads, stores or shares what your notifications say.

    TapClick any picture to see it larger.

  2. Choose an app and vibration pattern

    Pick an app from the list of apps on your phone, then choose the vibration pattern you'd like for it. Try a few: you'll soon learn to recognise each one.

    TapClick any picture to see it larger.

  3. Turn off the app's own vibration

    So you don't feel a double buzz, switch off the vibration in that app's own notification settings. Notibrate shows you how when you set up a pattern (pictures 4a and 4b above).

    If you use Vibrate mode, set the app's notification sound to Silent too, otherwise Android turns the sound into an extra buzz.

  4. Keep Notibrate running

    Some phones put apps to sleep to save battery. To stop this, go to Settings › Keep Notibrate running in Notibrate, tap Battery and choose Unrestricted (the names vary between phones).

    That's it. Your phone will now buzz differently for each app you've set up.
